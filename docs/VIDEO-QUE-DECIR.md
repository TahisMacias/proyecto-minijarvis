# Lo que tienes que decir

Lee de arriba a abajo. Lo que esta **en negrita** es lo que le dices a Elena.
Lo que esta entre corchetes es lo unico que tienes que hacer con las manos.

---

Soy Britany Macias, Desarrollo de Software, CENESTUR. Este es Mini-JARVIS, mi proyecto
integrador. La asistente se llama Elena y funciona por voz.

[ manten la barra espaciadora ]

**Hola Elena, ¿quien eres?**

[ suelta, y sigue hablando mientras ella responde ]

Miren la figura de la izquierda. Circulo turquesa latiendo: esta escuchando. Tres puntos
azules: esta pensando. Barras rosas: esta hablando. Se distinguen por color y por forma,
para que la aplicacion sirva tambien a una persona con daltonismo.

[ manten la barra espaciadora ]

**Elena, ¿cual es la raiz cuadrada de 3340?**

[ suelta, y sigue hablando ]

Un modelo de lenguaje predice texto, no calcula. Ahi se ve que pidio la herramienta:
Python hizo la cuenta y le devolvio el resultado exacto. Elena tiene diez herramientas, y
ninguna la ejecuta el modelo. El modelo solo pide. Mi codigo decide si se hace.

Aqui abajo esta el laboratorio. Analiza lo que acabo de decir con un Transformer real
corriendo en esta computadora.

[ pulsa el boton "ver los tokens" ]

Esta es mi frase cortada en pedazos, cada uno con su numero. El modelo no lee palabras:
lee numeros.

[ cierra ]

[ pulsa el boton "mapa de atencion" ]

Y esto es self-attention. Cada fila es una palabra preguntando a quien mirar, y lo rosa
es a quien mira. Se ve una diagonal brillante: cada palabra le presta casi toda su
atencion a la que tiene justo delante. Cada fila suma exactamente uno, porque la atencion
es una distribucion de probabilidad.

[ cierra ]

Los modelos que use: Whisper para pasar la voz a texto, Qwen tres punto ocho para pensar,
con Llama tres punto tres de alternativa, los tres por Together AI. Edge TTS para la voz.
Y BETO para el laboratorio. Ninguno lo entrene yo: todos son preentrenados. El codigo y
el informe tecnico estan en un repositorio publico. Gracias.
